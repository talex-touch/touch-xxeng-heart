# Lexi 功能指南

Lexi 是一个浏览器扩展，让你在正在读的网页里读懂技术英语，并把读过的词自然沉淀成词库。

这份指南覆盖扩展当前实际具备的全部功能。定位与设计原则见 [PRODUCT.md](../PRODUCT.md) 与 [DESIGN.md](../DESIGN.md)。

---

## 开始之前：两件必须知道的事

**一、AI 能力需要你自备服务。** Lexi 不内置任何 AI 密钥。划词翻译、页面翻译、内容速读、页面问答、实体检测等能力都要先在设置里配置一个 Provider（OpenAI / Anthropic / Gemini 协议均可，也支持兼容接口）。密钥保存在本机，请求由扩展后台发出，不经过任何第三方中转。

**二、内置翻译引擎默认是关闭的。** 设置里的 Microsoft Translator 和 Google Translate Web 两个传统引擎出厂即关闭状态，Google 这一项还需要你额外确认非官方接口的风险。**如果你装完扩展点「翻译此页」没有任何反应，通常就是既没配 Provider、也没开引擎。**

配置入口：扩展图标 → 打开设置 → 「供应商与功能」。

## 网页翻译

### 整页翻译

把整页正文逐段翻译，译文以安静的附注形式出现在原文下方，原文不动。

**五种触发方式**

| 方式 | 操作 |
| --- | --- |
| 侧边栏 | 打开侧栏 →「本页」→「翻译此页」 |
| 页面浮标 | 点击页面右下角的状态浮标（可在设置里关闭） |
| 键盘 | 在没有选中文字时，360 毫秒内**连按两下 Ctrl 或 Alt** |
| 规则自动恢复 | 命中你保存过的站点规则时自动开始 |
| 平台自动翻译 | 命中受支持平台且正文为英文时自动开始 |

**四种运行状态**（侧边栏会明确显示当前处于哪一种）

- **未运行** — 不会自动翻译任何页面
- **正在翻译** — 手动启动，可随时停止
- **已按规则恢复** — 由你保存的规则触发，暂停时规则会保留
- **平台自动翻译** — 由受支持平台规则触发

**启动时的四种范围**（默认始终是「仅本次」，避免误存规则）

| 范围 | 含义 |
| --- | --- |
| 仅本次 | 只翻译这一次，不保存规则 |
| 当前链接 | 保存规则，此链接下次访问自动恢复 |
| 当前站点 | 保存规则，该站点下的页面都自动翻译 |
| Regex | 保存规则，URL 命中正则的页面自动翻译 |

已保存的规则可在「设置 → 基础设置 → 划词翻译 → 已保存的页面规则」里查看、启用/停用和删除。**新规则只能从侧边栏的启动流程产生**，设置页只负责管理。

**平台自动翻译**支持三个平台，默认全部关闭，需要在设置里逐个开启：Discourse 主题帖、GitHub README、Reddit 帖子。它们只在正文确实是英文时才会触发。

### 划词翻译

选中网页上的任意文字即可翻译，译文以卡片形式出现在选区所在段落之后。

- 默认**需要按住修饰键**触发（macOS 是 Command，Windows/Linux 是 Ctrl），可在设置里改为选中即翻
- 也可以在选中后连按两下 Ctrl/Alt，或右键选择「使用 Lexi 翻译」
- 单次最长 5000 字符
- 卡片会显示译文、术语解释，以及来源、耗时、token 用量等指标
- 优先走传统翻译引擎，其次 AI，最后回落到本地词库

### 支持的语言

目前是**中英互译**，并且**日语和韩语页面可以翻译成中文**。

方向选项按目标语言命名——「译成中文」「译成英文」——因为源语言由翻译引擎自动检测，所以「译成中文」同样适用于日语和韩语页面。选择「自动判断」时，Lexi 会识别页面语言：中文页面译成英文，其他语言译成中文。

**词汇学习功能只针对英语。** 日语和韩语页面可以翻译，但不会产生生词替换或进入复习队列——那套能力是为中文母语者学英语设计的。

## 词汇学习

### 网页词汇替换

在你阅读的中文网页里，把部分中文词替换成对应的英文表达，用蓝色下划线标出。悬停即可看到原词、释义、音标和例句。

- **9 级学习等级**：从零基础到母语级，决定替换哪个难度区间的词
- **5 档密度**：极少（1%）到极度密集（35%）
- **三种显示方式**：只显示英文 / 只显示中文 / 中英双语对照
- **单页替换上限**可调（1–80）

悬停卡片上的「✓ 认识了，不再替换」会把该词永久移出替换池。

代码块、输入框和各类富文本编辑器（ProseMirror、CodeMirror、Monaco、Quill、TinyMCE 等）都不会被改动。

### 生词本与复习

划词翻译过的词、被替换过的词都会自动进入本地词库，并按间隔重复安排复习。

- 复习间隔从 1 天逐步延长到 240 天
- 复习时三档评价：不认识 / 模糊 / 认识；选「不认识」会退级并在 10 分钟后重来
- 侧边栏「记录」页可以看到待复盘队列、今日推荐和每日目标进度
- 词库支持导出与导入 JSON（设置 → 词库记录）

## 实体检测

边读边认出页面里的**专有名词**，并标出它所属的领域。覆盖六个领域：

技术工程 · 金融商业 · 产品与公司 · 医学生物 · 法律合规 · 学术论文

它的价值在于**按页面领域消歧**：同一个词在不同领域含义不同（比如 `position` 在金融页面是「持仓」、在技术页面是「位置」），Lexi 会先判断这一页属于哪个领域，再据此给出正确释义。

工作方式是内置种子词典 + AI 现场识别：词典覆盖高频专有名词，AI 补充词典之外的名字。侧边栏会显示「本页实体」及各领域分布。

设置入口在「基础设置」里，可以关闭标注、关闭 AI 补充、调整单页上限和缓存天数。用 AI 补充需要在「供应商与功能」里同时启用「实体检测」场景。

## 页面问答

针对当前页面提问，Lexi 会检索页面正文相关片段后回答。

- 默认快捷键 `mod+shift+m`（macOS 上 mod 是 Command，其他平台是 Ctrl），可在「自定义」里修改
- 采用检索式而非全文投喂，所以长页面也不会一次性把全文发出去
- 支持流式输出、随时中断、多轮追问
- 答案里的引用可点击，会滚动定位到原文并高亮

## 内容速读

在特定页面上生成结构化摘要卡片，说明读取范围与缓存状态。共三套：

| 卡片 | 覆盖范围 |
| --- | --- |
| 多平台速读 | Reddit、X、YouTube、Bilibili、小红书、知乎 |
| GitHub Digest | GitHub 仓库页，分快速与详细两级 |
| 论坛速读 | linux.do、idcflare.com 及通用 Discourse 站点，支持历史版本对比 |

三者都可以配置是否显示卡片、是否停留后自动生成、延迟秒数和缓存天数。检测到 NSFW 内容时默认不发送。

## 媒体工具

### AI Omni 媒体工具栏

按住 `meta+shift`（可配置）点击页面上的图片或视频，唤出工具栏：

- **提取还原 Prompt** — 截取视频当前帧或图片，让模型输出可复用的文生图 prompt
- **复制 Prompt**
- **下载媒体** — 保存到下载目录的 `Lexi/` 文件夹

### 视频倍速

- macOS：`Cmd + 右键` 点击视频
- Windows / Linux：`Ctrl + 左键` 点击视频

提供 1× / 1.25× / 1.5× / 2× / 3× / 4×，按 Esc 恢复原速。全屏下同样可用，页面内嵌的 iframe 视频也支持。

## 网页范围与敏感场景

**三级控制**：全局总开关 → 匹配模式（全部网页 / 仅白名单 / 排除黑名单）→ 按域名逐场景开关。

每个域名可以单独控制这些场景是否生效：网页词汇替换、划词翻译、每日推荐、内容速读、AI Omni、实体检测。

**内置停用的考试站点**：学习通（chaoxing.com、xuexitong.com、mooc1.chaoxing.com）和雨课堂（yuketang.cn、yuketang.com）出厂即为停用且标记为考试安全，不会做任何替换。这是强制执行的，不是默认值。

「特殊场景」里还预置了 X / Twitter 和 Discourse 论坛的适配配置，你也可以添加自定义场景。

## 请求限额

内置翻译引擎可以设置用量上限，避免付费渠道被意外消耗：

- 每日总请求上限
- 滚动窗口（N 小时内最多多少次）
- 允许运行的时段（例如只在 09:00–18:00 翻译）
- 每个引擎单独的日上限

超出限额时页面会给出明确提示并停止继续请求，而不是静默失败。

## 隐私与数据

**存在本机的**：词库与复习记录、访问日志、AI 调用日志、速读缓存、页面翻译缓存、所有设置。

**会发送出去的**：只有你主动触发的那次请求所需的内容——选中的文字、待翻译的段落、页面正文片段（问答与速读）、媒体帧（AI Omni）。发送目标是**你自己配置的 Provider**，Lexi 没有自己的服务器。

**API Key**：保存在本机 `storage.local`，请求由扩展后台发出，密钥不会进入网页上下文。

**非 HTTPS 端点需要逐个授权**：如果你配置了 http:// 的接口地址，Lexi 会要求你显式确认，并且这份授权名单只存在本机、不参与同步。

**关于同步**：开启「设置 → 基础设置 → 同步」后，配置会通过浏览器账号同步。⚠️ **`同步中包含 API Key` 这一项默认是开启的**，也就是说密钥会一并上传到浏览器厂商的同步服务器。如果你不希望如此，请手动关闭它。词库、AI 日志、访问记录、速读缓存和已确认的 HTTP 端点都不参与同步。

## 常见问题

**点了「翻译此页」没反应？**
最常见的原因是既没有配置 AI Provider、也没有启用内置翻译引擎（两个引擎出厂都是关闭的）。去「供应商与功能」检查一下。

**在学习通/雨课堂上不工作？**
这是刻意的。这两个平台被内置为考试安全站点，强制停用所有替换功能。

**支持哪些语言？**
中英互译，日语和韩语页面可以译成中文。词汇学习功能只覆盖英语。

**译文里为什么有些中文词变成了英文？**
那是词汇替换功能——Lexi 会在译文里植入你正在学的英文表达。可以在「词汇替换」里调整密度或直接关闭。

**会拖慢网页吗？**
词汇替换和翻译都按视口优先调度，只处理你正在看的部分。速读和实体检测都有缓存，同一页面不会重复请求。

**换了模型之后缓存还有效吗？**
速读和实体检测的缓存都带模型指纹，换 Provider 或模型后会自动失效重新生成。
